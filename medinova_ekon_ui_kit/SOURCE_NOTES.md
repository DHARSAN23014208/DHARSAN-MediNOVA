# Reference notes

The kit draws on the public Ekon listing/preview's described visual patterns: dark palette, editorial typography, marquee animations, animated counters, scrolling testimonials, portfolio-like hover interactions, and desktop/tablet/mobile responsive behavior.

- Ekon marketplace listing: https://www.framer.com/marketplace/templates/ekon/
- Public preview: https://ekon.framer.ai/

It does not include the Framer source file, licensed template assets, or copied proprietary components. The light theme and system-aware/manual theme switching are added for the requested MediNova use case; they are not presented as a claim about the Ekon template's own theme toggle.
